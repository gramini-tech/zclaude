Claude Code on your Z.ai GLM Coding Plan

zclaude asks which account a session should use, signs you in to Z.ai in the browser, lets you choose the GLM models for the main agent and its subagents, and then starts Claude Code with all of it passed through the environment. 

curl -fsSL https://vipincr.github.io/zclaude/install | bash

For a new Mac or Linux machine. Uses your Node.js when it is 20.17 or newer and brings a private copy only when it is missing or older. Installs Claude Code too if you do not have it. 

npx github:vipincr/zclaude self-install

Node.js already installed. npx github:vipincr/zclaude on its own runs it once without keeping anything. 

npm install -g github:vipincr/zclaude

A regular global npm install straight from GitHub.

git clone https://github.com/vipincr/zclaude.git && cd zclaude && npm install && ln -s "$PWD/zclaude" ~/.local/bin/zclaude

Work from a clone. The bash runner finds a suitable Node on its own.

Then open a new terminal and type zclaude.

What it does for you

  • Choose per launch

    A menu picks your Anthropic account or the Z.ai plan each time. Add your own entries as files in ~/.zclaude/profiles.

  • Browser sign-in

    Z.ai's own authorization page issues a coding-plan key named zclaude. On macOS the redirect is caught automatically; elsewhere you paste one URL.

  • Key in the Keychain

    The key lives in the macOS Keychain, or a 0600 file on Linux. It never lands in a shell rc file or in Claude Code's settings.

  • Separate models

    The main agent, subagents and background helpers each get a model from the list your plan returns, with context sizes shown.

  • Per-project choices

    Choices save to ./.zclaude/env or ~/.zclaude/settings. Neither holds secrets, so the project file can be committed.

  • Environment only

    Everything reaches Claude Code through its process environment. Your ~/.claude files are read and never written.

  • Run logs

    Each run writes a redacted JSON log. zclaude log shows the last one when something needs a closer look.

  • Updates itself

    Every push is a new version. A daily check tells you when one is out, and zclaude self-update installs it.

Usage

zclaude Menu, then launch. Signs in first if no valid key is stored.
zclaude -p "explain this repo" Any arguments after zclaude's own options go to claude.
zclaude --profile zai Skip the menu. --profile claude launches your normal Claude Code.
zclaude --reconfigure Choose the models again and save them per project or as your default.
zclaude login Sign in now, then optionally pick models and launch.
zclaude status Key, quota, models, config files and the current log file.
zclaude models Models your plan can use.
zclaude log The last run's log, for post-mortems. Add --json to share it.
zclaude self-update Update the same way zclaude was installed.
zclaude logout Forget the stored key on this machine.
zclaude -- --help Claude Code's own help. zclaude --help shows zclaude's.

Saved choices

# ./.zclaude/env  (or ~/.zclaude/settings for your default)
ZCLAUDE_MODEL=glm-5.3
ZCLAUDE_SUBAGENT_MODEL=glm-5.3-flash
ZCLAUDE_FAST_MODEL=glm-5.3-flash
ZCLAUDE_PROFILE=zai        # optional: skip the menu in this project

A command-line flag beats the environment, which beats the project file, which beats your user default. Every option and variable is listed in the README.

FAQ

What is zclaude?

A small launcher for Claude Code. It keeps your normal Claude Code setup untouched and, when you pick the Z.ai profile, starts Claude Code pointed at Z.ai's Anthropic-compatible endpoint with your coding-plan key and the GLM models you chose.

Is it made by Anthropic or Z.ai?

No. zclaude is an independent open-source project under the MIT license. It uses the environment variables Claude Code documents and the same browser sign-in that Z.ai's ZCode desktop app uses.

What do I need?

A Z.ai GLM Coding Plan subscription and a Mac or Linux machine. The curl installer adds Claude Code if it is missing, and Node.js only if yours is missing or older than 20.17. On Windows, install with npm; the sign-in asks you to paste the redirect URL.

Does it change my Claude Code settings?

No. It never writes to ~/.claude/settings.json, ~/.claude.json or any project .claude folder. Everything is passed in the environment of the one claude process it starts, so the moment you quit, nothing is left behind. The test suite checks this on every change.

My settings.json already sets ANTHROPIC_* variables. What happens?

Claude Code applies the env block of its settings file over the process environment, which would quietly undo the session zclaude set up. So zclaude shows each conflicting variable with both values and asks whether to stop so you can edit the file, or launch anyway. It does not edit the file for you.

Where is my key, and how do I remove it?

In the macOS Keychain under the service name zclaude, or in ~/.zclaude/credentials.json with 0600 permissions on Linux. zclaude logout removes the local copy. The key also exists on your Z.ai account; revoke it in the Z.ai API key console when you no longer need it.

Which models can I pick?

Whatever Z.ai's model list returns for your plan, such as glm-5.3, glm-5.3-flash and glm-4.7. The wizard also accepts a custom model id. Models with a 1M context window are passed to Claude Code with the [1m] suffix it expects.

How do I go back to my usual Claude Code?

Pick "Claude Code" in the menu, run zclaude --profile claude, or just run claude as before. Nothing about your usual setup was changed.

Will the installer replace my Node.js?

No. If node is 20.17 or newer it is used as is. If it is missing or older, the installer downloads an official, checksum-verified build into ~/.zclaude/node for zclaude alone and leaves your system Node and your PATH for Node untouched.

How do I update or uninstall?

zclaude self-update updates it the same way it was installed. To remove an installer-based setup, run curl -fsSL https://vipincr.github.io/zclaude/install | bash -s -- --uninstall; your settings and logs stay in ~/.zclaude until you delete them. For npm installs, use npm uninstall -g zclaude.

Something went wrong. What should I look at?

Run zclaude log. Every run records the profile, config files, key source and validation, each HTTP call with its status and timing, and how Claude Code was started and exited. Keys are redacted, so zclaude log --json is safe to attach to an issue.
